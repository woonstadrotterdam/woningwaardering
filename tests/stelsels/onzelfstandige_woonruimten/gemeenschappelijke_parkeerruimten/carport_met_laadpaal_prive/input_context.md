# carport_met_laadpaal_prive

## Doel

Test waardering van een carport (type II) met laadpaal die privé is (`gedeeldMetAantalOnzelfstandigeWoonruimten: 1`): volle privé-punten, niet gedeeld.

## Beleidsbron

- Implementatietoelichting: [§2.10.5 Laadpalen](../../../../../docs/implementatietoelichtingen/onzelfstandige-woonruimten.md#2105-laadpalen)
- Beleidsboek (quote): "Gemeenschappelijke parkeerruimten worden gewaardeerd per type parkeerplek."

## Handmatige berekening

| Onderdeel  | Aantal | Punten |
| ---------- | ------ | ------ |
| Type II    | 1      | 6      |
| Laadpaal   | 1      | 2      |
| **Totaal** |        | **8**  |
