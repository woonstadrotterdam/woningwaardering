# test_prive_carport_krijgt_geen_punten

Een privé-carport krijgt in deze rubriek geen punten.

Bron:
- implementatietoelichting onzelfstandige woonruimten, 2.8.3
- wettekst, Bijlage I onder A, toelichting rubriek 10 (via Bijlage I onder B, toelichting, inleiding)

## Rapport

Geen waarderingen voor Gemeenschappelijke parkeerruimten.

## Waarschuwingen

Geen.

## Input

```json
{
  "ruimten": [
    {
      "id": "carport",
      "soort": {
        "code": "BTR",
        "naam": "Buitenruimte"
      },
      "detailSoort": {
        "code": "CAR",
        "naam": "Carport"
      },
      "naam": "Carport",
      "oppervlakte": 12.0,
      "gedeeldMetAantalAdressen": 1
    }
  ]
}
```

{
  "criteriumGroep": {
    "stelsel": {
