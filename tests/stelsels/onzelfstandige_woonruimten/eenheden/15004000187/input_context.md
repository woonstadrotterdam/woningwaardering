# 15004000187

## Doel

Stelsel-ketentest voor onzelfstandige woonruimten met een geldig energielabel (NTA8800, label C) én een privé-balkon. Gebaseerd op eenheid 15004000185; toetst de interactie tussen energieprestatie op labelbasis en buitenruimten in de volledige keten.

Verwacht wordt **58 punten** totaal en een maximale huur van **€ 590,95**.
