# wastafel_toilet

## Doel

Test waardering van een wastafel in de toiletruimte (2.5 punten totaal).

## Beleidsbron

- Implementatietoelichting: [§2.6.1 Punten voor sanitaire basisvoorzieningen](../../../../../docs/implementatietoelichtingen/onzelfstandige-woonruimten.md#261-punten-voor-sanitaire-basisvoorzieningen)
- Beleidsboek (quote): "| Wastafel in vertrek/overige ruimte | Maximaal 1 per vertrek of overige ruimte\* |"

## Handmatige berekening

| Onderdeel                              | Aantal | Punten  |
| -------------------------------------- | ------ | ------- |
| Wastafel                               | 2      | 2       |
| Max 1.0 punt voor Wastafel             | —      | -1      |
| Meerpersoonswastafel                   | 2      | 3       |
| Max 1.5 punt voor Meerpersoonswastafel | —      | -1.5    |
| **Totaal**                             |        | **2.5** |
