# label_zonder_code

## Doel

Test dat een energielabel zonder `code` (alleen `naam`) niet als geldige energieprestatie telt: er worden geen punten toegekend op basis van het label.

## Beleidsbron

- Implementatietoelichting: [§2.4.3 Energieprestaties die niet geldig zijn](../../../../../docs/implementatietoelichtingen/onzelfstandige-woonruimten.md#243-energieprestaties-die-_niet_-geldig-zijn-voor-de-woningwaardering)
- Beleidsboek (quote): "Energieprestaties die niet geldig zijn voor de woningwaardering."
