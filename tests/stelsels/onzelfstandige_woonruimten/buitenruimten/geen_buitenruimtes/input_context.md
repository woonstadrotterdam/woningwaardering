# geen_buitenruimtes

## Doel

Test dat zonder buitenruimten geen punten worden toegekend in rubriek 8.

## Beleidsbron

- Implementatietoelichting: [§2.8 Rubriek 8: Buitenruimten](../../../../../docs/implementatietoelichtingen/onzelfstandige-woonruimten.md#28-rubriek-8-buitenruimten)
- Beleidsboek (quote):
  "Voor de aanwezigheid van privé-buitenruimte(n) worden 2 punten toegekend en vervolgens per vierkante meter 0,35 punt."
  (...)
  "Voor gemeenschappelijke buitenruimten worden 0,75 punten per vierkante meter toegekend:"

## Handmatige berekening

Geen buitenruimten aanwezig → 0 punten.
