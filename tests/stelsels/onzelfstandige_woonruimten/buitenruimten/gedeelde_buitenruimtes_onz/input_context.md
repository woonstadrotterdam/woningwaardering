# gedeelde_buitenruimtes_onz

## Doel

Test waardering van gedeelde buitenruimten: punten per m² worden verdeeld over onzelfstandige woonruimten met toegang en gebruiksrecht.

## Beleidsbron

- Implementatietoelichting: [§2.8 Rubriek 8: Buitenruimten](../../../../../docs/implementatietoelichtingen/onzelfstandige-woonruimten.md#28-rubriek-8-buitenruimten)
- Beleidsboek (quote): "Voor gemeenschappelijke buitenruimten worden 0,75 punten per vierkante meter toegekend:"
  (...)
  "daarna gedeeld door het aantal onzelfstandige woonruimten op het adres dat toegang en gebruiksrecht heeft."

## Handmatige berekening

| Onderdeel  | Aantal | Adressen | Onz. | Punten   |
| ---------- | ------ | -------- | ---- | -------- |
| Tuin       | 6      | 2        | —    | 1.05     |
| Tuin       | 6      | 3        | 2    | 0.75     |
| Afronding  |        |          |      | -0.05    |
| **Totaal** |        |          |      | **1.75** |

## Opmerkingen

- De twee tuinen hebben verschillende deel-factoren (adressen / onzelfstandige).
