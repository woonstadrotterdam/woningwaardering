# warning_geen_oppervlakte

## Doel

Test dat een waarschuwing volgt wanneer een buitenruimte geen oppervlakte heeft. De warning is implementatiegedrag bij incomplete input; zonder oppervlakte kan de m²-component van rubriek 8 niet worden berekend.

## Beleidsbron

- Implementatietoelichting: [§2.8.1 Punten voor privé-buitenruimte](../../../../../docs/implementatietoelichtingen/onzelfstandige-woonruimten.md#281-punten-voor-privé-buitenruimte)
- Beleidsboek (quote): "Voor de aanwezigheid van privé-buitenruimte(n) worden 2 punten toegekend en vervolgens per vierkante meter 0,35 punt."
