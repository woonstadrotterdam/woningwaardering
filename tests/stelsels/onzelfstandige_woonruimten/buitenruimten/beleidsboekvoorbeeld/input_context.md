# beleidsboekvoorbeeld

## Doel

Rekenvoorbeeld uit het beleidsboek: combinatie van privé-buitenruimten met verwacht totaal van 5.25 punten.

## Beleidsbron

- Implementatietoelichting: [§2.8 Rubriek 8: Buitenruimten](../../../../../docs/implementatietoelichtingen/onzelfstandige-woonruimten.md#28-rubriek-8-buitenruimten)
- Beleidsboek (quote): "Voor de aanwezigheid van privé-buitenruimte(n) worden 2 punten toegekend en vervolgens per vierkante meter 0,35 punt."

## Handmatige berekening

| Onderdeel                    | Aantal | Adressen | Onz. | Punten   |
| ---------------------------- | ------ | -------- | ---- | -------- |
| Klein balkon                 | 1      | —        | —    | 0.35     |
| Privé buitenruimten aanwezig | —      | —        | —    | 2        |
| Balkon                       | 4.5    | —        | 4    | 0.84375  |
| Dakterras                    | 52     | 5        | 4    | 1.95     |
| Afronding                    |        |          |      | 0.11     |
| **Totaal**                   |        |          |      | **5.25** |

## Opmerkingen

- Privé-buitenruimten (klein balkon + aanwezigheidsbonus) worden niet gedeeld; balkon en dakterras wel.
