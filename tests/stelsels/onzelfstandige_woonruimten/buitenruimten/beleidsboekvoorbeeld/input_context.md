# beleidsboekvoorbeeld

## Doel

Rekenvoorbeeld uit het beleidsboek: combinatie van privé-buitenruimten met verwacht totaal van 5.25 punten.

## Beleidsbron

- Implementatietoelichting: [§2.8 Rubriek 8: Buitenruimten](../../../../../docs/implementatietoelichtingen/onzelfstandige-woonruimten.md#28-rubriek-8-buitenruimten)
- Beleidsboek (quote): "Buitenruimten worden gewaardeerd op basis van oppervlakte en type."

## Handmatige berekening

| Onderdeel                    | Aantal | Punten  |
| ---------------------------- | ------ | ------- |
| Klein balkon                 | 1      | 0.35    |
| Privé buitenruimten aanwezig | —      | 2       |
| Balkon                       | 4.5    | 0.84375 |
| Dakterras                    | 52     | 1.95    |

## Opmerkingen

- Gedeeld met 4 onzelfstandige woonruimten; punten worden verdeeld.
