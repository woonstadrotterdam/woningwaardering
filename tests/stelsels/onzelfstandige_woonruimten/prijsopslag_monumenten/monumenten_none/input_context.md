# monumenten_none

## Doel

Test dat zonder monumentstatus geen opslag wordt toegepast.

## Beleidsbron

- Implementatietoelichting: [§2.14 Rubriek 14: Opslagen](../../../../../docs/implementatietoelichtingen/onzelfstandige-woonruimten.md#214-rubriek-14-opslagen)
- Beleidsboek (quote): "Maar het woningwaarderingsstelsel maakt het ook mogelijkheid om bovenop de maximale huurprijs op basis van punten nog een opslag te rekenen in bepaalde situaties."
