# monumenten_none

## Doel

Test dat zonder monumentstatus geen opslag wordt toegepast.

## Beleidsbron

- Implementatietoelichting: [§2.14 Rubriek 14: Opslagen](../../../../../docs/implementatietoelichtingen/onzelfstandige-woonruimten.md#214-rubriek-14-opslagen)
- Beleidsboek (quote): "Bovenop de maximale huurprijs op basis van punten kan een opslag worden toegepast voor monumenten en beschermde stads- of dorpsgezichten."
