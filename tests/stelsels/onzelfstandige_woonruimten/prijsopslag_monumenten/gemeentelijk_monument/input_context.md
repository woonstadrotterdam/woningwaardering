# gemeentelijk_monument

## Doel

Test gemeentelijk monument met verwachte opslag van 15% op de maximale huurprijs.

## Beleidsbron

- Implementatietoelichting: [§2.13.4 Gemeentelijke en provinciale monumenten](../../../../../docs/implementatietoelichtingen/onzelfstandige-woonruimten.md#2145-gemeentelijke-en-provinciale-monumenten)
- Beleidsboek (quote): "Indien aan de voorwaarden wordt voldaan dan wordt de maximale huurprijs vermeerderd met 15%."
