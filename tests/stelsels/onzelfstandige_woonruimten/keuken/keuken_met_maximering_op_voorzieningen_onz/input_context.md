# keuken_met_maximering_op_voorzieningen_onz

## Doel

Test dat keukenvoorzieningen buiten de keukenruimte niet meetellen voor extra punten.

## Beleidsbron

- Implementatietoelichting: [§2.5.3 Punten voor extra voorzieningen keuken](../../../../../docs/implementatietoelichtingen/onzelfstandige-woonruimten.md#253-punten-voor-extra-voorzieningen-keuken)
- Beleidsboek (quote): "Als het aantal punten voor de extra voorzieningen hoger uitvalt, dan wordt dit afgetopt."

## Handmatige berekening

| Onderdeel                             | Aantal | Adressen | Onz. | Punten |
| ------------------------------------- | ------ | -------- | ---- | ------ |
| Lengte aanrecht                       | 1000   | —        | 2    | 2      |
| Inbouw koelkast                       | 4      | —        | 2    | 2      |
| Inbouw oven elektrisch                | 1      | —        | 2    | 0.5    |
| Maximaal evenveel punten als aanrecht | —      |          |      | -0.5   |
| **Totaal**                            |        |          |      | **4**  |

## Opmerkingen

- Gedeeld met 2 onzelfstandige woonruimten; punten worden verdeeld.
