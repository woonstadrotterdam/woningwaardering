# aanrecht_3m_8_onz

## Doel

Test aanrechtpunten (3m_8) in een gedeelde keuken, verdeeld over 8 onzelfstandige woonruimten.

## Beleidsbron

- Implementatietoelichting: [§2.5.2 Punten voor basisvoorzieningen keuken](../../../../../docs/implementatietoelichtingen/onzelfstandige-woonruimten.md#252-punten-voor-basisvoorzieningen-keuken)
- Beleidsboek (quote): "Er worden 13 punten toegekend mits er _minimaal_ 8 onzelfstandige wooneenheden toegang en gebruiksrecht hebben tot de keuken."

## Handmatige berekening

| Onderdeel       | Aantal | Punten      |
| --------------- | ------ | ----------- |
| Lengte aanrecht | 3001   | 1.63 → 1.75 |
| **Totaal**      |        | **1.75**    |

## Opmerkingen

- Gedeeld met 8 onzelfstandige woonruimten; punten worden verdeeld.
