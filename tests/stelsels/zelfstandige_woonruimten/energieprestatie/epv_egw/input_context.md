# epv_egw

## Doel

Test dat bij een energieprestatievergoeding (EPV) een eengezinswoning een vast puntenaantal krijgt, ongeacht het energielabel.

De input bevat een eengezinswoning met geldige energie-index (label C) en prijscomponent EPV. Verwacht: **32 punten** onder **Energieprestatievergoeding Eengezinswoning**.

## Beleidsbron

- Implementatietoelichting: [§2.4.6.3 Energieprestatievergoeding](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#2463-energieprestatievergoeding)
- Beleidsboek (quote): "Bij een EPV wordt voor een eengezinswoning 32 punten toegekend voor de energieprestatie en bij een meergezinswoning 28 punten."

## Handmatige berekening

| Situatie            | Punten |
| ------------------- | ------ |
| EPV eengezinswoning | 32     |
