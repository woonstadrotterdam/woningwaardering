# geen_woz

## Doel

Test dat zonder relevante WOZ-waarde de minimum WOZ-waarde (€ 85.806) wordt gebruikt én dat voor nieuwbouw 2016 de minimum van 40 punten geldt.

## Beleidsbron

- Implementatietoelichting: [§2.11.1 Waarderingsmethode WOZ-waarde](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#2111-waarderingsmethode-woz-waarde), [§2.11.5 Uitzondering nieuwbouw 2015–2019](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#2115-uitzondering-waardering-nieuwbouwwoningen-opgeleverd-tussen-2015---2019)
- Beleidsboek (quote): "De minimum WOZ-waarde komt pas aan bod als er voor een woonruimte geen relevante WOZ-waarde aanwezig is én de verhuurder geen taxatierapport (zoals hierboven bedoeld) heeft ingediend."

## Opmerkingen

- De berekende punten op basis van de minimum WOZ-waarde (10,40) worden verhoogd naar 40 door de nieuwbouwregel.
