# max_33_procent

## Doel

Test de WOZ-cap: maximaal 33% van het totale puntenaantal mag uit WOZ-waarde bestaan. De berekende WOZ-punten (82,33) worden teruggebracht naar **66,00 punten** (33% van 200 totaalpunten).

## Beleidsbron

- Implementatietoelichting: [§2.11.7 Uitzonderingen op de WOZ-cap](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#2117-de-uitzonderingen-op-de-woz-cap)
- Beleidsboek (quote): "Het aandeel van de WOZ-waarde in de puntenwaardering is gemaximeerd. Dat betekent dat maximaal 33% van het totale puntenaantal van een woning bepaald mag worden door de WOZ-waarde van de woning."

## Handmatige berekening

| Stap                          | Punten |
| ----------------------------- | ------ |
| Berekende WOZ-punten (I + II) | 82,33  |
| Maximaal 33% van 200 totaal   | 66,00  |
| Correctie                     | −16,33 |
| **Totaal**                    | **66** |
