# warning_corop_geen_gebruiksoppervlakte

## Doel

Test dat een waarschuwing volgt wanneer de eenheid in COROP Amsterdam/Utrecht ligt (bouwjaar 2018-2022) maar geen gebruiksoppervlakte heeft om de < 40 m²-voorwaarde te toetsen.

## Beleidsbron

- Implementatietoelichting: [§2.11.6 Kleine nieuwbouw COROP Utrecht/Amsterdam](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#2116-uitzonderingsregel-waardering-kleine-nieuwbouwwoningen-in-corop-gebied-utrechtamsterdam-opgeleverd-tussen-2018---2022)
- Beleidsboek (quote): "de woning is kleiner dan 40 m²"
