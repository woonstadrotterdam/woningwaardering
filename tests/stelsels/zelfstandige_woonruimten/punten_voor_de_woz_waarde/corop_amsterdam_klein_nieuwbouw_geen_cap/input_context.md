# corop_amsterdam_klein_nieuwbouw_geen_cap

## Doel

Test dat de WOZ-cap niet wordt toegepast bij een kleine nieuwbouwwoning (< 40 m²) in COROP-gebied Amsterdam (bouwjaar 2020), ook wanneer het totaal zonder cap ≥ 187 punten zou zijn. Verwacht: volledige WOZ-punten met factor II € 103, zonder maximering.
