# hoogniveau_renovatie_waarde

## Doel

Test dat een hoogniveaurenovatie in 2019 (bouwjaar 2016) de nieuwbouw-minimumregel activeert: berekende WOZ-punten worden verhoogd naar **40 punten**.

## Beleidsbron

- Implementatietoelichting: [§2.11.5 Uitzondering nieuwbouw 2015–2019](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#2115-uitzondering-waardering-nieuwbouwwoningen-opgeleverd-tussen-2015---2019)
- Beleidsboek (quote): "er is sprake van verbouw waarna de woning voldoet aan de op dat moment geldende energieprestatie-eisen voor nieuwbouwwoningen."

## Opmerkingen

- De implementatie koppelt hoogniveaurenovatie aan bouwjaar 2015–2019, niet aan het renovatie-attribuut alleen — zie [§2.11.5](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#2115-uitzondering-waardering-nieuwbouwwoningen-opgeleverd-tussen-2015---2019).
