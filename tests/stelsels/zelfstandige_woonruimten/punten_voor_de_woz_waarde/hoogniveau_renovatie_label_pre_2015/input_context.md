# hoogniveau_renovatie_label_pre_2015

## Doel

Test dat hoogniveaurenovatie vóór 2015 (renovatiedatum 31-12-2014) géén minimum van 40 WOZ-punten oplevert; verwacht **34,75 punten** (gewone berekening).

## Beleidsbron

- Implementatietoelichting: [§2.11.5 Uitzondering nieuwbouw 2015–2019](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#2115-uitzondering-waardering-nieuwbouwwoningen-opgeleverd-tussen-2015---2019)
- Beleidsboek (quote): "de nieuwbouw of verbouw heeft plaatsgevonden in de jaren 2015-2019"
