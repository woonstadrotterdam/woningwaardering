# geen_buitenruimtes

## Doel

Test dat een woning zonder privé- of gemeenschappelijke buitenruimte **5 minpunten** krijgt.

De input bevat geen ruimten. Verwacht wordt één waarderingsregel **Geen buitenruimten** met **−5 punten**.

## Beleidsbron

- Implementatietoelichting: [§2.8.6 Minpunten bij geen enkele buitenruimte](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#285-minpunten-bij-geen-enkele-buitenruimte)
- Beleidsboek (quote): "Als een woning helemaal geen privé-buitenruimte, gemeenschappelijk buitenruimte of loggia heeft, dan geldt een aftrek van 5 punten."

## Handmatige berekening

| Situatie           | Punten |
| ------------------ | ------ |
| Geen buitenruimten | −5     |
