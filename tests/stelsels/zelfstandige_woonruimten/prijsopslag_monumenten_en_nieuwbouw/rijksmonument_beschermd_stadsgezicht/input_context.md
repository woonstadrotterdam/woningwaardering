# rijksmonument_beschermd_stadsgezicht

## Doel

Test dat bij cumulatie van rijksmonument en beschermd stadsgezicht alleen de hoogste monumentenopslag geldt: rijksmonument (**35%**) prevaleert; stadsgezichtopslag (5%) wordt niet toegevoegd.

## Beleidsbron

- Implementatietoelichting: [§2.13.1 Cumulatie van opslagen beperkt mogelijk](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#2131-cumulatie-van-opslagen-beperkt-mogelijk)
- Beleidsboek (quote): "de monumentenopslag (zowel de Rijksmonumenten als provinciale en gemeentelijke monumenten) en de opslag voor een beschermd stads- of dorpsgezicht niet tegelijkertijd voor dezelfde woonruimte worden toegekend"

## Handmatige berekening

| Monumentstatus                              | Opslag            |
| ------------------------------------------- | ----------------- |
| Rijksmonument                               | 35%               |
| Rijksbeschermd stadsgezicht (bouwjaar 1964) | niet cumuleerbaar |
| **Totaal**                                  | **35%**           |

## Opmerkingen

- Nieuwbouwopslag zou wél cumuleerbaar zijn met monumentenopslag, maar speelt hier geen rol.
