# beschermd_stadsgezicht_bouwjaar_1965

## Doel

Test dat een woning in een rijksbeschermd stadsgezicht met bouwjaar 1965 géén opslag krijgt, omdat de woning niet vóór 1965 is gebouwd. **0%** opslag.

## Beleidsbron

- Implementatietoelichting: [§2.13.5 Beschermd dorps- en stadsgezicht](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#2136-beschermd-dorps--en-stadsgezicht)
- Beleidsboek (quote): "de woonruimte behoort tot een woning die is gebouwd vóór 1965"

## Handmatige berekening

| Criterium                   | Bouwjaar | Opslag |
| --------------------------- | -------- | ------ |
| Rijksbeschermd stadsgezicht | 1965 → 0 | 0%     |

## Opmerkingen

- De grens is strikt: gebouwd vóór 1965 is vereist; 1965 zelf valt buiten de opslag.
