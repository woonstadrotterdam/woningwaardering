# beschermd_stadsgezicht_zonder_bouwjaar

## Doel

Test dat een rijksbeschermd stadsgezicht zonder opgegeven bouwjaar geen opslag oplevert (**0%**), omdat niet aangetoond kan worden dat de woning vóór 1965 is gebouwd.

## Beleidsbron

- Implementatietoelichting: [§2.13.5 Beschermd dorps- en stadsgezicht](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#2136-beschermd-dorps--en-stadsgezicht)
- Beleidsboek (quote): "de woonruimte behoort tot een woning die is gebouwd vóór 1965"

## Handmatige berekening

| Criterium                   | Bouwjaar  | Opslag |
| --------------------------- | --------- | ------ |
| Rijksbeschermd stadsgezicht | ontbreekt | 0%     |

## Opmerkingen

- Zonder bouwjaar kan de voorwaarde niet worden gecontroleerd; de verhuurder moet dit aantonen (passief beleid).
