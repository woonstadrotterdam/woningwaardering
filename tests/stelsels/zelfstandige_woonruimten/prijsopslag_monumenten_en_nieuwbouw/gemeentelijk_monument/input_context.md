# gemeentelijk_monument

## Doel

Test dat een gemeentelijk monument een prijsopslag van **15%** op de maximale huurprijs oplevert.

## Beleidsbron

- Implementatietoelichting: [§2.13.4 Gemeentelijke en provinciale monumenten](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#2135-gemeentelijke-en-provinciale-monumenten)
- Beleidsboek (quote): "+ 15% op de maximale huurprijs"

## Handmatige berekening

| Criterium                            | Opslag     |
| ------------------------------------ | ---------- |
| Gemeentelijk of provinciaal monument | 15% (0,15) |
| **Totaal**                           | **0**      |

## Opmerkingen

- De Huurcommissie hanteert passief beleid: de verhuurder moet aantonen dat de woning is aangewezen als monument.
