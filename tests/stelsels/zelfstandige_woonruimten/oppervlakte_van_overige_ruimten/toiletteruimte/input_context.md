# toiletteruimte

## Doel

Test de minimale oppervlakte van 2 m² voor overige ruimten: een toiletruimte van 1,9 m² telt niet mee; een toiletruimte van 2,1 m² wel. Afgerond totaal 2 m² × 0,75 = **1,5 punt**.

## Beleidsbron

- Implementatietoelichting: [§2.2.2.2 De voorwaarden van een overige ruimte](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#2222-de-voorwaarden-van-een-overige-ruimte)
- Beleidsboek (quote): "De ruimte moet een minimale oppervlakte van 2,00 m² hebben (1,95 m² voldoet hier dus niet aan);"

## Handmatige berekening

| Toiletruimte | Oppervlakte | Meetelt?           |
| ------------ | ----------- | ------------------ |
| Space_1      | 1,9 m²      | nee                |
| Space_2      | 2,1 m²      | ja → 2 m² afgerond |
| **Punten**   | 2 × 0,75    | **1,5**            |

## Opmerkingen

- Afronding gebeurt op het totaal van alle overige ruimten; zie [§2.2.2.1](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#2221-afronding-op-hele-m²).
