# garagebox

## Doel

Test dat twee privé garageboxen (elk 15 m², `Ruimtesoort.overige_ruimte`) worden gewaardeerd met 0,75 punt per m². Totaal 30 m² → **22,5 punten**.

## Beleidsbron

- Implementatietoelichting: [§2.2.2 Overige ruimten](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#222-overige-ruimten)
- Beleidsboek (quote): "Een overige ruimte wordt gewaardeerd met 0,75 punt per m² in rubriek 2."

## Handmatige berekening

| Ruimte       | Oppervlakte | Punten (0,75 p/m²)   |
| ------------ | ----------- | -------------------- |
| Garagebox 1  | 15 m²       | (in totaal)          |
| Garagebox 2  | 15 m²       |                      |
| Som afgerond | 30 m²       | 30 × 0,75 = **22,5** |

## Opmerkingen

- Privé parkeerruimte binnen de woning wordt als overige ruimte gewaardeerd; zie [§2.2.2.5](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#2225-privé-parkeerruimte).
