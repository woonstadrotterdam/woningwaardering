# 37101000032

## Opmerkingen

Ketentest voor het volledige waarderingsstelsel zelfstandige woonruimte op basis van een VERA-export van eenheid **37101000032** (eengezinswoning bouwjaar 1924).
Grote eenheid (33 ruimten) met meer dan 250 punten; triggert aparte berekening bij hoge puntentotalen.

- Totaal 284 punten over alle rubrieken.
