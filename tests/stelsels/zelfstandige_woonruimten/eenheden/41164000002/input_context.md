# 41164000002

## Opmerkingen

Ketentest voor het volledige waarderingsstelsel zelfstandige woonruimte op basis van een VERA-export van eenheid **41164000002** (eengezinswoning bouwjaar 1904).
Grote woning (20 ruimten, vier slaapkamers) met beperkte sanitaire bouwkundige elementen in de VERA-export.

- Totaal 256 punten; rubriek sanitair 8 punten.
