# 71211000027

## Opmerkingen

Ketentest voor het volledige waarderingsstelsel zelfstandige woonruimte op basis van een VERA-export van eenheid **71211000027** (eengezinswoning bouwjaar 1919).
Zolder met vlizotrap en twee tuinen in de VERA-export.

- Vlizotrap aanwezig: zolder wordt niet bestraft met −5 m²-punten.

Verwacht wordt **142 punten** totaal.
