# 23003000050

## Opmerkingen

Ketentest voor het volledige waarderingsstelsel zelfstandige woonruimte op basis van een VERA-export van eenheid **23003000050** (etagewoning, meergezinswoning bouwjaar 1921).
Bevat privé-tuin en gemengde ruimte-indeling typisch voor oudere etagewoningen.

Verwacht wordt **155 punten** totaal.
