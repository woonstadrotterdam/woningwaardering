# 81020000003

## Opmerkingen

Ketentest voor het volledige waarderingsstelsel zelfstandige woonruimte op basis van een VERA-export van eenheid **81020000003** (eengezinswoning bouwjaar 1923).
Oudere eengezinswoning met hoge energieprestatiepunten (52) in de output.

Verwacht wordt **220 punten** totaal.
