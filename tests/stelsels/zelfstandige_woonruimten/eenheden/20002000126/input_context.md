# 20002000126

## Doel

Ketentest voor het volledige waarderingsstelsel zelfstandige woonruimte op basis van een VERA-export van eenheid **20002000126** (stadswonen, meergezinswoning bouwjaar 1993).
Compacte eenheid met berging als overige ruimte; energielabel F levert minpunten op.
