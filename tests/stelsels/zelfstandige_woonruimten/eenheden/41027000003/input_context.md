# 41027000003

## Opmerkingen

Ketentest voor het volledige waarderingsstelsel zelfstandige woonruimte op basis van een VERA-export van eenheid **41027000003** (trappenhuisflat, meergezinswoning bouwjaar 1948).
Vijf ingebouwde kasten en negatieve energieprestatiepunten (label/index).

Verwacht wordt **107 punten** totaal.
