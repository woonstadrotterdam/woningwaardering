# 81065000089

## Opmerkingen

Ketentest voor het volledige waarderingsstelsel zelfstandige woonruimte op basis van een VERA-export van eenheid **81065000089** (eengezinswoning bouwjaar 1921).
Zolder met vlizotrap; minpunten buitenruimten (−5) door ontbrekende privé-buitenruimte.

Verwacht wordt **144 punten** totaal.
