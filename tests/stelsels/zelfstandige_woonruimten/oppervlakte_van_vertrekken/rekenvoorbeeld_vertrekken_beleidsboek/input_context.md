# rekenvoorbeeld_vertrekken_beleidsboek

## Doel

Test het rekenvoorbeeld uit het beleidsboek voor afronding van vertrekoppervlakten: kamer 15,49 m² en keuken 11,24 m² worden samen afgerond naar **27 punten** (1 punt per m²).

## Beleidsbron

- Implementatietoelichting: [§2.2.1.1 Afronden op hele m²](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#2211-afronden-op-hele-m²)
- Beleidsboek (quote): "Tel de uitkomsten van alle vertrekken samen bij elkaar op. Bij een getal dat eindigt op 0,50 m² wordt afgerond omhoog."

## Handmatige berekening

| Vertrek    | Oppervlakte (2 decimalen) |
| ---------- | ------------------------- |
| Kamer      | 15,49 m²                  |
| Keuken     | 11,24 m²                  |
| Som        | 26,73 m² → 27 m²          |
| **Punten** | **27** (1 p/m²)           |

## Opmerkingen

- De individuele ruimten worden per regel getoond met hun gemeten oppervlakte; het eindtotaal volgt de som-afrondering op hele m².
