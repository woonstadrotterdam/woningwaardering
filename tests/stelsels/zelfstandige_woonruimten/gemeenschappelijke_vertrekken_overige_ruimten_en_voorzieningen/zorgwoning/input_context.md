# zorgwoning

## Doel

Test de forfaitaire waardering van gemeenschappelijke ruimten en voorzieningen in een zorgwoning.

De input bevat `doelgroep` Zorg en een woonkamer (zonder gemeenschappelijke ruimten). Verwacht: **3 punten** onder **Zorgwoning**.

## Beleidsbron

- Implementatietoelichting: [§2.9.4 Gemeenschappelijke ruimten en voorzieningen in een zorgwoning](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#294-gemeenschappelijke-ruimten-en-voorzieningen-in-een-zorgwoning)
- Beleidsboek (quote): "Om arbeidsintensief meetwerk te voorkomen kent de Huurcommissie in dat geval een waardering van 3 punten per woning toe."

## Handmatige berekening

| Situatie             | Punten |
| -------------------- | ------ |
| Zorgwoning (forfait) | 3      |
| **Totaal**           | **3**  |

## Opmerkingen

- Bij doelgroep Zorg hoeven gemeenschappelijke ruimten niet individueel te worden gespecificeerd; zie implementatietoelichting.
