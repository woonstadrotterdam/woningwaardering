# max_4_punten_overige_ruimten

## Doel

Test maximering van verwarmde overige ruimten: 5 verwarmde bergingen (5 × 1) worden afgetopt op **4 punten**.

## Beleidsbron

- Implementatietoelichting: [§2.3 Rubriek 3: Verwarming en verkoeling](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#23-rubriek-3-verwarming-en-verkoeling)
- Beleidsboek (quote): "1 punt per verwarmde overige ruimte of verkeersruimte (tot maximaal 4 punten)"

## Handmatige berekening

| Stap                  | Punten |
| --------------------- | ------ |
| 5 verwarmde bergingen | 5,00   |
| Maximum               | 4,00   |
| Correctie             | −1,00  |
| **Totaal**            | **4**  |
