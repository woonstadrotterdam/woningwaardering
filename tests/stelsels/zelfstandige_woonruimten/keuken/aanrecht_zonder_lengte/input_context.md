# aanrecht_zonder_lengte

## Doel

Test dat een keuken met een aanrecht zonder opgegeven lengte niet gewaardeerd wordt en **0 punten** oplevert.

## Beleidsbron

- Implementatietoelichting: [§2.5.1 De basiseisen voor een keuken](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#251-de-basiseisen-voor-een-keuken)
- Beleidsboek (quote): "een aanrechtblad van minimaal 1 meter lengte in één stuk"

## Handmatige berekening

| Onderdeel  | Lengte    | Punten |
| ---------- | --------- | ------ |
| Aanrecht   | ontbreekt | 0      |
| **Totaal** |           | **0**  |

## Opmerkingen

- Zonder meetbare lengte kan het aanrecht niet aan de basiseis voldoen; de implementatie slaat het element over met een waarschuwing.
