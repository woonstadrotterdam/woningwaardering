# keukenvoorziening_niet_in_keuken

## Doel

Test dat keukenvoorzieningen (2× inbouwkoelkast) in een badkamer niet meetellen voor rubriek 5. Alleen het aanrecht in de keuken (1000 mm) levert **4 punten** op.

## Beleidsbron

- Implementatietoelichting: [§2.5.3 Punten voor extra voorzieningen keuken](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#253-punten-voor-extra-voorzieningen-keuken)
- Beleidsboek (quote): extra voorzieningen tellen mee "in de keuken".

## Handmatige berekening

| Ruimte               | Onderdeel          | Punten            |
| -------------------- | ------------------ | ----------------- |
| Keuken               | Aanrecht 1000 mm   | 4                 |
| Badkamer             | 2× inbouw koelkast | 0 (buiten keuken) |
| **Totaal rubriek 5** |                    | **4**             |
| **Totaal**           |                    | **4**             |

## Opmerkingen

- Installaties worden per ruimte gewaardeerd; voorzieningen buiten de keukenruimte vallen niet onder deze stelselgroep.
