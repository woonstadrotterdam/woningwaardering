# keuken_met_maximering_op_voorzieningen

## Doel

Test maximering wanneer extra voorzieningen het aanrecht overstijgen: aanrecht 1000 mm (4 punten) plus 4× koelkast en 1× oven (5 punten bruto) worden afgetopt met **−1 punt**. Totaal **8 punten**.

## Beleidsbron

- Implementatietoelichting: [§2.5.3 Punten voor extra voorzieningen keuken](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#253-punten-voor-extra-voorzieningen-keuken)
- Beleidsboek (quote): "Als het aantal punten voor de extra voorzieningen hoger uitvalt, dan wordt dit afgetopt."

## Handmatige berekening

| Onderdeel                     | Aantal | Punten per stuk | Totaal |
| ----------------------------- | ------ | --------------- | ------ |
| Aanrecht 1000 mm              | 1      | 4               | 4      |
| Inbouw koelkast               | 4      | 1               | 4      |
| Inbouw oven elektrisch        | 1      | 1               | 1      |
| Subtotaal extra voorzieningen |        |                 | 5      |
| Maximering (aftrek)           |        |                 | −1     |
| **Totaal**                    |        |                 | **8**  |
