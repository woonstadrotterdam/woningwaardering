# keuken_met_twee_koelkasten

## Doel

Test dat meerdere identieke extra voorzieningen (2× inbouwkoelkast) elk afzonderlijk meetellen: aanrecht 1000 mm (4 punten) plus 2× koelkast (2 punten) = **6 punten**.

## Beleidsbron

- Implementatietoelichting: [§2.5.3 Punten voor extra voorzieningen keuken](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#253-punten-voor-extra-voorzieningen-keuken)
- Beleidsboek (quote): "Inbouw koelkast" levert 1 punt per stuk op.

## Handmatige berekening

| Onderdeel        | Aantal | Punten per stuk | Totaal |
| ---------------- | ------ | --------------- | ------ |
| Aanrecht 1000 mm | 1      | 4               | 4      |
| Inbouw koelkast  | 2      | 1               | 2      |
| Afronding        |        | 1               |        |
| **Totaal**       |        |                 | **6**  |
