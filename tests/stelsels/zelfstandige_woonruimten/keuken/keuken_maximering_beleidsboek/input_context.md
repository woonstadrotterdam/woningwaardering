# keuken_maximering_beleidsboek

## Doel

Test het beleidsboekvoorbeeld voor maximering van extra keukenvoorzieningen: aanrecht 1600 mm (4 punten) plus extra voorzieningen die samen 4,5 punt zouden opleveren, worden afgetopt tot 4 punten. Totaal **8 punten**.

## Beleidsbron

- Implementatietoelichting: [§2.5.3 Punten voor extra voorzieningen keuken](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#253-punten-voor-extra-voorzieningen-keuken)
- Beleidsboek (quote): "Het aantal punten voor de extra voorzieningen kan niet meer zijn dan het aantal punten voor de basisvoorzieningen (de aanrechtlengte)."

## Handmatige berekening

| Onderdeel                     | Punten   |
| ----------------------------- | -------- |
| Aanrecht 1600 mm              | 4        |
| Inbouw kookplaat inductie     | 1,75     |
| Inbouw afzuiginstallatie      | 0,75     |
| Inbouw oven elektrisch        | 1,00     |
| Inbouw koelkast               | 1,00     |
| Subtotaal extra voorzieningen | 4,50     |
| Maximering (aftrek)           | −0,50    |
| **Totaal**                    | **8,00** |

## Opmerkingen

- Dit testcase volgt het rekenvoorbeeld uit de implementatietoelichting letterlijk na.
