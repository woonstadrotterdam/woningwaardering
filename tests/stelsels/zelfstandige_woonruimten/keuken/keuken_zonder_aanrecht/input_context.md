# keuken_zonder_aanrecht

## Doel

Test dat een keukenruimte zonder aanrecht niet voldoet aan de basiseisen en **0 punten** oplevert in rubriek 5.

## Beleidsbron

- Implementatietoelichting: [§2.5.1 De basiseisen voor een keuken](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#251-de-basiseisen-voor-een-keuken)
- Beleidsboek (quote): "een aanrechtblad van minimaal 1 meter lengte in één stuk"

## Handmatige berekening

| Onderdeel              | Punten |
| ---------------------- | ------ |
| Keuken zonder aanrecht | 0      |

## Opmerkingen

- Zonder geldig aanrecht (≥ 1000 mm) wordt de ruimte niet als keuken gewaardeerd, ook al is de detailsoort `keuken`.
