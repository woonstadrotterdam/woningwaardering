# carport_met_laadpaal_niet_gedeeld

## Doel

Test een privé-carport (niet gedeeld: `gedeeldMetAantalAdressen` 1) met laadpaal als bouwkundig element.

Verwacht: **8 punten** — type II carport (6) + laadpaal (2).

## Beleidsbron

- Implementatietoelichting: [§2.10.3 Punten per soort parkeerplek](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#2103-punten-per-soort-parkeerplek), [§2.10.5 Laadpalen](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#2105-laadpalen)
- Beleidsboek (quote): "Type II: een parkeerplek buiten behorende tot het complex of de woning met dak (hieronder telt een carport)"

## Handmatige berekening

| Component               | Berekening | Punten |
| ----------------------- | ---------- | ------ |
| Type II carport (privé) | 6 / 1      | 6      |
| Laadpaal (privé)        | 2 / 1      | 2      |
| **Totaal**              |            | **8**  |

## Opmerkingen

- Privé-parkeerruimte wordt niet gedeeld door het aantal adressen; zie groep **Privé** in de output.
