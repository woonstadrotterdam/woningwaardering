# drempelloze_inrijdouche_en_bad

## Doel

Test dat een drempelloze inrijdouche samen met een bad als bad/douchecombinatie wordt gewaardeerd: **7 punten** (niet 4 + 6).

## Beleidsbron

- Implementatietoelichting: [§2.6.1 Sanitaire basisvoorzieningen](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#261-punten-voor-sanitaire-basisvoorzieningen)
- Beleidsboek (quote): "Bad/douche | 7"

## Handmatige berekening

| Onderdeel     | Aantal | Punten |
| ------------- | ------ | ------ |
| Bad en douche | 1      | 7      |
| **Totaal**    |        | **7**  |

## Opmerkingen

- Aanwezigheid van zowel bad als douche (inrijdouche) leidt tot één bad/douche-voorziening.
