# toilet_aparte_ruimte

## Doel

Test waardering van hangend (3,75) en staand (3,00) toilet in een toiletruimte: totaal **6,75 punten**.

## Beleidsbron

- Implementatietoelichting: [§2.6.1 Sanitaire basisvoorzieningen](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#261-punten-voor-sanitaire-basisvoorzieningen)
- Beleidsboek (quote): "Hangend toilet in een toiletruimte — 3,75 punten" en "Toilet (staand) in een toiletruimte — 3 punten"

## Handmatige berekening

| Voorziening    | Punten |
| -------------- | ------ |
| Hangend toilet | 3,75   |
| Staand toilet  | 3,00   |
| Totaal         | 6,75   |
