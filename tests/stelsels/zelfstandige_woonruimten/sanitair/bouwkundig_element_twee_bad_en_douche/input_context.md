# bouwkundig_element_twee_bad_en_douche

## Doel

Test dat twee bad/douchecombinaties als bouwkundige elementen elk apart worden geteld: 2 × 7 = **14 punten**.

## Beleidsbron

- Implementatietoelichting: [§2.6.1 Sanitaire basisvoorzieningen](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#261-punten-voor-sanitaire-basisvoorzieningen)
- Beleidsboek (quote): "Bad/douche | 7"

| Voorziening | Aantal | Punten per stuk | Totaal |
| ----------- | ------ | --------------- | ------ |
| Bad/douche  | 2      | 7 → 14          | 14     |
