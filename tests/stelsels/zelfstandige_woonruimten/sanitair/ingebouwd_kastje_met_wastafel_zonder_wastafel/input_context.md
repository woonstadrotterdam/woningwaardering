# ingebouwd_kastje_met_wastafel_zonder_wastafel

## Doel

Test dat een ingebouwd kastje met wastafel alleen als extra voorziening telt als er ook een wastafel als basisvoorziening aanwezig is. Zonder wastafel: **0 punten**.

## Beleidsbron

- Implementatietoelichting: [§2.6.2 Extra sanitaire voorzieningen](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#262-punten-voor-extra-sanitaire-voorzieningen)
- Beleidsboek (quote): "Voor een ingebouwde kast met wastafel moet de wastafel als aparte voorziening worden meegegeven."

## Opmerkingen

- Extra sanitaire voorzieningen vereisen bovendien een bad of douche in de ruimte.
