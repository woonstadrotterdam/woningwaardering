# douche_slaapkamer

## Doel

Test dat een douche in een slaapkamer (niet alleen badkamer/toiletruimte) **4 punten** oplevert.

## Beleidsbron

- Implementatietoelichting: [§2.6 Rubriek 6: Sanitair](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#26-rubriek-6-sanitair)
- Beleidsboek (quote): "De waardering van sanitair is niet beperkt tot de badkamer en toiletruimte, maar kan ook gaan over sanitaire voorzieningen in andere ruimten. Bijvoorbeeld een douche in een woon- of slaapkamer."
