# bouwkundig_element_geen_sanitair

## Doel

Test dat een bouwkundig element zonder sanitaire detailsoort geen punten oplevert in rubriek 6.

## Beleidsbron

- Implementatietoelichting: [§2.6 Rubriek 6: Sanitair](../../../../../docs/implementatietoelichtingen/zelfstandige-woonruimten.md#26-rubriek-6-sanitair)
- Beleidsboek (quote): "Sanitair in de woonruimte komt voor waardering in aanmerking."

## Opmerkingen

- Alleen elementen met een erkende sanitaire detailsoort worden gewaardeerd.
